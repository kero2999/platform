قبل إنشاء حسابك

الملخص ده يساعدك تفهم الخدمة. افتح الروابط لقراءة التفاصيل كاملة قبل الموافقة.

  • فتح الفصول التالية واستحقاق الشهادة مرتبطان باستيفاء متطلبات التقييم الخاصة بالكورس، وليس الدفع وحده.
  • الحساب شخصي. لا تشارك بيانات الدخول أو تنشر محتوى الكورسات دون إذن.
  • نحفظ بيانات الحساب وتقدّمك وإجاباتك ونتائج التقييم لتشغيل الخدمة ومتابعة تعلّمك.
  • قد تُعالج رسائلك وإجابات التطبيق والمشروع بواسطة مزوّد الذكاء الاصطناعي لتقديم الرد والتقييم. لا تكتب بيانات حساسة أو معلومات تخص أشخاصًا آخرين.
  • الدفع يتم عبر مزوّد الدفع. طلب الإلغاء أو الاسترداد يخضع للسياسة ومراجعة الدعم؛ إرسال الطلب لا يعيد المال تلقائيًا.
  • هذا المربع لا يُعد موافقة على تسجيل جلسات التصفح أو تلقي رسائل تسويقية، ولا يسقط حقوقك المقررة قانونًا.

إصدار الوثائق: 2026-10-28.1. نسجّل وقت موافقتك وإصدار الوثائق المرتبط بها.

أنشئ حسابًا مجانيًا لتصفح الكورسات، حفظ تقدمك، وتجربة المحتوى قبل الشراء.
